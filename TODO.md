# Что дальше

Этот файл раньше описывал первоначальный план: «Шаг 0 → Шаг 8», стек с
LiveKit и MVP из пяти пунктов, за пределы которого выходить было нельзя.
Всё это давно позади — план выполнен целиком, LiveKit заменён на собственный
SFU на mediasoup (см. [DEPLOY.md](DEPLOY.md)), а «бэклог, который не трогаем»
успел стать основной частью приложения.

Актуальное состояние стека и инфраструктуры — в [README.md](README.md),
[RUN.md](RUN.md) и [DEPLOY.md](DEPLOY.md). Здесь только то, что впереди.

## Десктоп

Каркас Electron есть (`desktop/`), но приложения из него пока не собрать:

- [ ] `electron-builder` в зависимостях и блок `build` в `desktop/package.json`
      (appId, цели, иконки) — сейчас скрипт `npm run build` есть, а самого
      сборщика нет
- [ ] иконки приложения (`.ico`, `.icns`, png)
- [ ] упаковать веб-билд в пакет: `main.js` грузит `../web/dist`, а
      electron-builder кладёт только `desktop/`
- [ ] отдельная сборка веба для десктопа — с абсолютными `VITE_API_URL` и
      `VITE_WS_URL`; текущий `web/.env.production` пуст, потому что рассчитан
      на single-origin
- [ ] демонстрация экрана: с Electron 17+ `getDisplayMedia()` не открывает
      системный диалог сам, нужен `setDisplayMediaRequestHandler` +
      свой пикер на `desktopCapturer`
- [ ] трей и жизнь после закрытия окна (сейчас закрыл окно — вышел из
      приложения)
- [ ] push-to-talk глобальным хоткеем — главная причина ставить десктоп
      вместо вкладки
- [ ] автозапуск при входе в систему, бейдж непрочитанного в таскбаре
- [ ] автообновление (`electron-updater` + GitHub Releases). Протокол gateway
      живой, без автообновления клиенты будут молча разъезжаться с сервером
- [ ] подпись кода: на Windows иначе SmartScreen, на macOS без нотаризации
      приложение просто не запустится
- [ ] сборка десктопа в CI и релизы по тегу

## Тесты

- [ ] Фронтенд не покрыт вообще. Начинать не с компонентов, а с чистой
      логики: `gateway.tsx` (реконнект, watchdog, очередь), `outbox.ts`

      сравнения
- [ ] `sfu/` тоже без тестов

## Безопасность

- [ ] JWT лежит в `localStorage` — единственный неисправленный пункт из
      код-ревью. Переезд на httpOnly-cookie упирается в то, что токен нужен
      WebSocket-шлюзу и SFU в query-строке
- [ ] `coturn:latest` в dev-compose (в прод-файле версия уже прибита)

## Архитектура

- [ ] `web/src/hooks/useGatewayEvents.ts` — около тысячи строк и ~35
      обработчиков в одном `useEffect`. Из `AppShell` это уже вынесли, но
      одним блоком оно и осталось; логичнее, чтобы каждая фича подписывалась
      рядом с местом использования
- [ ] SFU держит состояние комнат только в памяти процесса — горизонтально
      не масштабируется. Пока не нужно, но это потолок
