## Проект
PskovCord — аналог Discord для группы друзей. Обычное клиент-серверное веб-приложение, деплоим на наш реальный сервер (НЕ self-hosted, центральный бэкенд один). Монорепо, дальше развиваем сами.
Имя временное: только через константу/env APP_NAME, нигде не хардкодить.

## Подход
Веб-first: сначала браузерный клиент, потом обернём его в Electron как у Discord (тонкая обёртка над тем же билдом). Мобилки — позже, не сейчас.

## Стек (используй этот, если не предложишь явно лучше в первом же ответе)
- Фронт: React + Vite + TypeScript; LiveKit React SDK (@livekit/components-react) для голоса/видео/экрана
- Бэкенд: Django + Django Channels (WebSocket) + DRF
- БД: PostgreSQL; Redis (presence + channel layer)
- Голос/видео/демонстрация экрана/вебка: LiveKit (open-source SFU) — SFU руками не пишем, только генерим токены на бэке
- Docker Compose поднимает весь стек локально и его же деплоим на сервер

## MVP (только это, остальное — в бэклог, не трогаем)
1. Auth: регистрация, логин (JWT)
2. Сервер + текстовые каналы внутри
3. Текстовый чат в реальном времени (WebSocket)
4. Голосовой канал: несколько человек, звук через WebRTC (LiveKit)
5. Присутствие: кто онлайн и кто в голосовом канале

## План работы — строго по шагам, по одному за сообщение:
Шаг 0. Скелет монорепо: структура папок (backend/, web/), docker-compose.yml (postgres, redis, livekit, backend), .env.example с APP_NAME, README с командой запуска. Скелет должен быть рабочим — `docker compose up` уже что-то поднимает.
Шаг 1. Backend: инициализация Django, settings, подключение к PostgreSQL/Redis, base app.
Шаг 2. Модели данных MVP + миграции (User, Server, Channel, Message, membership).
Шаг 3. Auth: регистрация/логин на JWT, эндпоинты DRF.
Шаг 4. WebSocket-чат: Channels consumer, отправка/получение сообщений в канале.
Шаг 5. Presence через Redis.
Шаг 6. LiveKit: генерация токенов на бэке, вход в голосовой канал.
Шаг 7. Веб-клиент (React+Vite): auth → список серверов/каналов → текстовый чат → голосовой канал (LiveKit-компоненты).
Шаг 8. Electron: тонкая обёртка над готовым веб-билдом, отдельный конфиг сборки.
