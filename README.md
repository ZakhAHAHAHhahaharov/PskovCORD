# PskovCord

Аналог Discord для группы друзей — сервера, каналы, чат в реальном времени и
голосовая связь. Веб-first клиент-серверное приложение, монорепо.

> Имя временное и живёт только в `APP_NAME` (env). Нигде не хардкодить.

Продакшн: **https://pskord.zlgvpn.org**

Инструкции по запуску и деплою — в [RUN.md](RUN.md) и [DEPLOY.md](DEPLOY.md)
(они ближе к актуальному состоянию инфраструктуры, чем README, и не дублируются
здесь специально — детали реализации быстро устаревают).
