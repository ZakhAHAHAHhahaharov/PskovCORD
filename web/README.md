# web/ — веб-клиент PskovCord

Пусто до **Шага 7**. Здесь будет React + Vite + TypeScript клиент:
auth → список серверов/каналов → текстовый чат → голосовой канал (LiveKit).

Дизайн: привычная раскладка Discord (рейл серверов слева, колонка каналов,
чат по центру, панель пользователя снизу-слева, участники справа) — кнопки
на своих местах.
